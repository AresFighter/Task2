# Приложение с использованием паттерна "Наблюдатель"

## Описание
Данный проект демонстрирует использование паттерна "Наблюдатель" для создания приложения, в котором несколько компонентов реагируют на изменения состояния таймера. Приложение включает в себя текстовый компонент, музыкальный компонент и анимационный компонент, которые синхронизируются с таймером и выполняют свои задачи в зависимости от его состояния.

## Функциональность
1. **Текстовый компонент**:
   - Отображает текущее время в текстовом поле.
   - Может быть запущен и остановлен пользователем.

2. **Музыкальный компонент**:
   - Воспроизводит звуковой файл через заданные интервалы времени.
   - Пользователь может задать интервал и количество повторений.

3. **Анимационный компонент**:
   - Отображает анимацию цветка на холсте.
   - Анимация запускается через заданные интервалы времени.

4. **Управление таймером**:
   - Пользователь может запускать, останавливать и сбрасывать таймер.
   - Все компоненты синхронизируются с таймером и обновляются в зависимости от его состояния.

## Используемые технологии
- **Язык программирования**: Java
- **Фреймворк**: JavaFX — для создания графического интерфейса и анимации.
- **[**Паттерны**](https://sites.google.com/view/study-pattern/%D0%B3%D0%BB%D0%B0%D0%B2%D0%BD%D0%B0%D1%8F?authuser=0) проектирования**:
  - **Наблюдатель**: Для синхронизации компонентов с таймером.

## Пример использования
1. Запустите приложение.
2. Нажмите кнопку "Старт" для запуска таймера.
3. Используйте кнопки "Старт" и "Стоп" для управления текстовым компонентом.
4. Введите интервал и количество повторений для музыкального компонента и нажмите "Старт".
5. Введите период для анимационного компонента и нажмите "Старт".
6. Нажмите "Стоп" для остановки любого из компонентов.
7. Нажмите "Сброс" для сброса таймера и всех компонентов.

## Применение
Проект разработан в учебных целях для демонстрации работы паттерна "Наблюдатель" и интеграции с JavaFX для создания интерактивного графического интерфейса.
