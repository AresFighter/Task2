# Графический редактор с использованием паттерна "Декоратор"

## Описание
Данный проект представляет собой графический редактор, который позволяет рисовать различные геометрические фигуры (круг, квадрат, прямоугольник, треугольник, пятиугольник) с возможностью настройки их внешнего вида. Проект демонстрирует использование паттерна "Декоратор" для добавления дополнительных свойств к фигурам, таких как цвет контура и толщина контура.

## Функциональность
1. **Рисование фигур**:
   - Пользователь может выбирать из списка доступных фигур: круг, квадрат, прямоугольник, треугольник, пятиугольник.
   - Фигуры рисуются на холсте с помощью мыши.
2. **Настройка внешнего вида**:
   - **Цвет заливки**: Пользователь может выбрать сплошной цвет, градиент или текстуру для заливки фигуры.
   - **Цвет контура**: Пользователь может выбрать цвет контура фигуры.
   - **Толщина контура**: Пользователь может задать толщину контура фигуры.
3. **Анимация**:
   - Пользователь может включить анимацию для фигур, которая изменяет их прозрачность.
4. **Управление холстом**:
   - **Очистка холста**: Пользователь может очистить холст от всех фигур.
   - **Отмена и повтор действий**: Пользователь может отменять и повторять действия с фигурами.

## Используемые технологии
- **Язык программирования**: Java
- **Фреймворк**: JavaFX — для создания графического интерфейса и отображения фигур.
- **[**Паттерны**](https://sites.google.com/view/study-pattern/%D0%B3%D0%BB%D0%B0%D0%B2%D0%BD%D0%B0%D1%8F?authuser=0) проектирования**:
  - **Декоратор (Decorator)**: Для добавления дополнительных свойств к фигурам (цвет контура, толщина контура).
  - **Прототип (Prototype)**: Для клонирования фигур при рисовании.

## Пример использования
1. Запустите приложение.
2. Выберите фигуру из списка.
3. Настройте цвет заливки, цвет контура и толщину контура.
4. Нажмите на холст, чтобы нарисовать фигуру.
5. Включите анимацию, чтобы увидеть изменение прозрачности фигур.
6. Используйте кнопки "Отмена" и "Повтор" для управления действиями.
7. Нажмите "Очистить холст", чтобы удалить все фигуры.

## Применение
Проект разработан в учебных целях для демонстрации работы паттерна "Декоратор" и интеграции с JavaFX для создания интерактивного графического интерфейса.
