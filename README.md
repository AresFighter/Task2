# Слайд-шоу с индикатором прогресса

## Описание
Данный проект представляет собой приложение для просмотра изображений в режиме слайд-шоу с индикатором прогресса. Пользователь может выбирать папку с изображениями, просматривать их вручную или автоматически, а также видеть текущий прогресс просмотра на индикаторе.

## Функциональность
1. **Выбор папки с изображениями**: Пользователь может выбрать папку, содержащую изображения, с помощью диалогового окна.
2. **Просмотр изображений**:
   - **Ручной режим**: Пользователь может переключаться между изображениями с помощью кнопок "Вперед", "Назад", "Первый слайд" и "Последний слайд".
   - **Автоматический режим**: Включение слайд-шоу с автоматическим переключением изображений через заданный интервал времени.
3. **Индикатор прогресса**: Отображение текущего положения слайда и общего количества слайдов. Индикатор включает в себя линию прогресса, текстовые метки и указатель текущего слайда.
4. **Управление слайд-шоу**:
   - **Старт/Стоп**: пользователь может запустить или остановить автоматическое слайд-шоу.
   - **Обновление индикатора**: индикатор обновляется при каждом изменении текущего слайда.

## Используемые технологии
- **Язык програмтирования**: Java
- **Фреймворк**: JavaFX — для создания графического интерфейса и отображения изображений.
- **[**Паттерны**](https://sites.google.com/view/study-pattern/%D0%B3%D0%BB%D0%B0%D0%B2%D0%BD%D0%B0%D1%8F?authuser=0) проектирования**:
  - **Итератор**: для последовательного перебора изображений.
  - **Строитель**: для создания и настройки индикатора прогресса.

## Пример использования
1. Нажмите кнопку "Выбрать папку" и выберите папку с изображениями.
2. Изображения загрузятся, и на экране отобразится первое изображение.
3. Используйте кнопки "Вперед", "Назад", "Первый слайд" и "Последний слайд" для ручного переключения между изображениями.
4. Нажмите кнопку "Старт" для запуска автоматического слайд-шоу.
5. Нажмите кнопку "Стоп" для остановки слайд-шоу.
6. Индикатор прогресса будет отображать текущий слайд и общее количество слайдов.

## Применение
Проект разработан в учебных целях для демонстрации работы с паттернами проектирования (Итератор, Строитель) и интеграции с JavaFX для создания интерактивного графического интерфейса.
